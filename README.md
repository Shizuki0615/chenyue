### 三、二改之后如果要公开，请不要公开内置字卡

- 自己改、自己用，都没有问题。
- 但如果改完要公开出去（公开部署、公开分享给他人），请不要把系统内置字卡一起公开。
- 内置字卡是系统预设的内容；公开的二改版本，请只保留你自己添加的字卡，不要把内置字卡打包进去。

### 四、二改可以自加云存储，但请不要公开云存储

- 这个网站的存储都是保存在个人设备本地的，不会上传至任何网络，本站也不会加云存储。
- 云存储之前有人提过，但因为这个字卡使用人数越来越多，不会考虑加了——现在人太多，会有各种风险（安全风险等），所以不加。
- 停更之后你可以拿代码去二改，自己加上云存储、部署私人使用，但请不要公开。公开有云存储给其他人使用，因为使用网站的人太多了，可能会引来麻烦，给你我双方都带来困扰。
