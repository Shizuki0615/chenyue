写于 2026-10-24。本文件是为「换一个对话做 UI 精修」准备的交接说明：

## 一、先确认仓库状态（每次动工第一件事）

```bash
cd /workspace
git branch --show-current
git log --oneline -1
git status --short
```

这个工作区出现过多次「检出位置漂移」：提交落在 `main`，但工作树被切到
`backup/reading-together`，HEAD 变成环境自动提交 `feat: update workspace`，
于是 `src/` 看起来像是退回了旧版本。

判断方法：`git log main --oneline -1` 如果比当前 HEAD 新，说明你的改动在 main 上。
处理：`git checkout main`。不要重写代码，也不要以为功能丢了。

另外：编辑器有时会提示「文件被修改」，那多半只是 checkout 造成的，
先跑 `git status` 核实，别当成用户手动改过。

功能基线：`main` = `7f91fcc`（错过七天），与 `origin/main`、`origin/backup/reading-together` 三方一致。
此后如果只多了文档提交，功能代码不变。

## 二、构建与哨兵（最容易踩坑的地方）

```bash
node build.mjs                     # 构建：写 index.html / js/*.js / sw.js / version.json
node build.mjs --check-sentinels   # 只检查，不写产物
node build.mjs --allow-revert      # 跳过打回体检，放行构建
```

产物结构：`src/` 拼装成 `index.html`（含 HTML 与全部 CSS）+ 外置 `js/*.js`（83 个）
+ `sw.js` + `version.json`。GitHub Pages 直接 serve `main` 分支的产物，没有 CI。

哨兵登记表在 `build.mjs` 的 `const FIX_SENTINELS = [...]`，当前 4479 条，每条形如：

```js
{ name: '#1551a 说明（删＝会坏成什么样）', file: 'js/reading.js', needle: '精确的一行代码片段' },
```

规则：

- 改 needle 叫重锚，允许。删掉登记的整条叫缩尺，构建会中止。
- 重锚那一轮必然报一次「打回体检少了 N 条」，因为体检拿 HEAD 的旧 needle
  去比对工作树。这是预期行为，不是真丢了修复。确认自己确实只改了锚点，
  再用 `node build.mjs --allow-revert` 放行。提交之后 HEAD 更新，下一轮就不再报。
- needle 必须是单行。多行 needle 在产物里匹配不到。
- needle 不能只落在注释里，也不能和别的哨兵共用同一段文本，
  否则会报哑哨兵（A 锚点指错 / B 共用 needle / C 针在注释里）。

精修 CSS 时特别注意，`src/css/reading.css` 里有 7 条哨兵的 needle 指向具体样式行：

```
#1551m .rd-ledger[hidden]{display:none!important}
#1553g .rd-spine{position:absolute;right:3px;
#1553i @media (prefers-reduced-motion: reduce){.rd-buddy-av.on::after{animation:none;opacity:.45}}
#1554a min-height:0;padding:0 0 24px}
#1554b .rd-grid{display:grid;grid-template-columns:repeat(3,1fr);gap:14px;padding:0 16px}
```

改到这几行就会触发重锚流程，属正常，按上面流程走即可。

## 三、本轮范围与边界

只动视觉：颜色、字号、间距、圆角、阴影、动效、层级。

不要动：

- 任何功能行为（翻页判定、批注生成、封存/错过七天的触发条件、同读计时）
- `data-*` 属性、元素 id、class 名里被 JS 引用的部分
  （例如 `rd-mark`、`rd-pop-old`、`rd-buddy-av` 的 `on`、`#rd-buddy` 的
  `rd-tog` / `rd-pace` / `rd-buddy-same-text`）
- `[hidden]` 那一条兜底规则（`.rd-shelf[hidden]...{display:none!important}`），
  删了所有面板都会关不掉

如果某个视觉改动必须动结构，先停下来问，不要顺手重写。
